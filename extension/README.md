# Atoll: расширение для браузера

Расширение для **Chrome, Edge, Brave и Firefox** (Manifest V3, один и тот же пакет) к острову [Atoll](../README.md):

- **Проверка текста через [LanguageTool](https://languagetool.org)**: выделите текст, правый клик → «Проверить текст», или `Alt+Shift+L`.
  На странице появится карточка с замечаниями и подсказками, кнопка «Скопировать исправленный текст». На острове в пилюле
  покажется итог («LanguageTool · замечаний: 3»).
- **Заметки**: правый клик по выделенному → «Сохранить в заметки Atoll» или `Alt+Shift+N`. Заметка с названием и адресом страницы
  появится на вкладке «Заметки» острова.
- **Окно расширения** (значок на панели): вставьте текст, проверьте, нажмите подсказку, чтобы заменить фрагмент.

Расширение ничего не делает само: проверка и заметка выполняются только по вашему нажатию или горячей клавише.

## Установка

1. В Atoll: **Настройки → Поведение → Расширение для браузера**: включите связь и нажмите **«Скопировать ключ»**.
2. Установите расширение в браузер (см. ниже).
3. В настройках расширения (правый клик по значку → «Параметры» / «Управление расширением» → «Настройки») вставьте ключ и нажмите «Сохранить и проверить связь». Должно появиться «Остров на связи».

**Chrome, Edge, Brave.** Откройте `chrome://extensions` (в Edge `edge://extensions`), включите «Режим разработчика» → **«Загрузить распакованное»** → выберите папку `extension/`.

**Firefox** (версия 128 или новее).
- *Попробовать:* откройте `about:debugging#/runtime/this-firefox` → **«Загрузить временное дополнение…»** → выберите файл `extension/manifest.json`. Такое дополнение работает до перезапуска Firefox.
- *Поставить насовсем:* обычный Firefox принимает только дополнения, подписанные Mozilla. Подпись бесплатная: на [addons.mozilla.org](https://addons.mozilla.org/developers/) отправьте zip с содержимым папки `extension/` как «самостоятельно распространяемое» дополнение и получите подписанный `.xpi`, который ставится двойным щелчком. Без подписи насовсем ставится только в Firefox Developer Edition / Nightly (в `about:config` выключить `xpinstall.signatures.required`).
- При установке Firefox покажет, что расширение передаёт «содержимое сайтов»: это выделенный вами текст, который уходит на сервер LanguageTool при проверке.

## LanguageTool и приватность

По умолчанию используется публичный `https://api.languagetool.org`: **выделенный текст отправляется туда** (только когда вы запускаете
проверку; лимит бесплатного сервера: 20 000 знаков и 20 запросов в минуту). Если не хотите отправлять текст наружу, разверните свой сервер
LanguageTool и впишите его адрес в параметрах (например `http://localhost:8081`): браузер спросит разрешение на доступ к нему.

Остров получает только число замечаний и заметки, которые вы сами сохраняете. Протокол и защита: [docs/extension-bridge.md](../docs/extension-bridge.md).

## Разработка и тесты

Без зависимостей (чистый JavaScript).

```bash
cd extension
npm test        # юнит-тесты: клиент LanguageTool, связь с островом (мок-серверы), проверки манифеста
npm run e2e     # сквозной тест в Chromium с загруженным расширением (нужен Playwright)
```

Структура: `manifest.json`; `src/background.js` (меню и горячие клавиши), `src/bridge.js` (связь с островом),
`src/languagetool.js` (клиент), `src/overlay.js` (карточка на странице), `popup.*`, `options.*`; тексты в `_locales/{ru,en}`.
В Firefox тот же файл фона работает как фоновый скрипт, в Chrome — как сервис-воркер (в `manifest.json` указаны оба).

Автотесты запускают расширение в настоящем Chromium. **В Firefox автоматический прогон не делается** (его нельзя загрузить с расширением в тестовой среде): манифест проверяется статически (`test/manifest.test.mjs`), а саму работу в Firefox нужно проверить руками.
