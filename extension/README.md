# Atoll: расширение для браузера

Расширение для Chrome, Edge, Brave (Manifest V3) к острову [Atoll](../README.md):

- **Проверка текста через [LanguageTool](https://languagetool.org)**: выделите текст, правый клик → «Проверить текст», или `Alt+Shift+L`.
  На странице появится карточка с замечаниями и подсказками, кнопка «Скопировать исправленный текст». На острове в пилюле
  покажется итог («LanguageTool · замечаний: 3»).
- **Заметки**: правый клик по выделенному → «Сохранить в заметки Atoll» или `Alt+Shift+N`. Заметка с названием и адресом страницы
  появится на вкладке «Заметки» острова.
- **Окно расширения** (значок на панели): вставьте текст, проверьте, нажмите подсказку, чтобы заменить фрагмент.

Расширение ничего не делает само: проверка и заметка выполняются только по вашему нажатию или горячей клавише.

## Установка

1. В Atoll: **Настройки → Поведение → Расширение для браузера**: включите связь и нажмите **«Скопировать ключ»**.
2. В браузере откройте `chrome://extensions`, включите «Режим разработчика» → **«Загрузить распакованное»** → выберите эту папку `extension/`.
3. В настройках расширения (правый клик по значку → «Параметры») вставьте ключ и нажмите «Сохранить и проверить связь». Должно появиться «Остров на связи».

## LanguageTool и приватность

По умолчанию используется публичный `https://api.languagetool.org`: **выделенный текст отправляется туда** (только когда вы запускаете
проверку; лимит бесплатного сервера: 20 000 знаков и 20 запросов в минуту). Если не хотите отправлять текст наружу, разверните свой сервер
LanguageTool и впишите его адрес в параметрах (например `http://localhost:8081`): браузер спросит разрешение на доступ к нему.

Остров получает только число замечаний и заметки, которые вы сами сохраняете. Протокол и защита: [docs/extension-bridge.md](../docs/extension-bridge.md).

## Разработка и тесты

Без зависимостей (чистый JavaScript).

```bash
cd extension
npm test        # юнит-тесты: клиент LanguageTool, связь с островом (мок-серверы)
npm run e2e     # сквозной тест в Chromium с загруженным расширением (нужен Playwright)
```

Структура: `manifest.json`; `src/background.js` (меню и горячие клавиши), `src/bridge.js` (связь с островом),
`src/languagetool.js` (клиент), `src/overlay.js` (карточка на странице), `popup.*`, `options.*`; тексты в `_locales/{ru,en}`.
Firefox пока не поддерживается.
