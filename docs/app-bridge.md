# Мост для других приложений

Остров слушает `http://localhost:47811` (только эта машина). Кроме Claude Code, через него можно показывать на острове
события **своих** программ: короткое уведомление и «живую активность» в свёрнутой пилюле (прогресс, таймер).

## Доступ

- Только `POST`, `Content-Type: application/json`, тело до 1 МБ.
- Заголовок `X-Island-Token: <секрет>`. Секрет лежит в `%LOCALAPPDATA%\DynamicIsland\bridge.token` и читается только вашим пользователем Windows.
- Запросы со страниц сайтов (с заголовком `Origin` или `Referer`) отклоняются, поэтому вызывать мост должна **программа**, а не сайт в браузере.
- Всё остаётся на этом ПК, остров ничего не отправляет наружу. Если остров не запущен, соединение просто не откроется: приложению нужно молча это пережить.

## `POST /app/notify`: уведомление

```json
{ "app": "Daily Note", "title": "Пора записать день", "text": "Сегодня 3 из 5 задач", "url": "https://daily-notes-io.vercel.app/" }
```

Появляется всплывающим уведомлением (не показывается при «Не беспокоить», а пока вы печатаете ждёт паузы).
`url` необязателен, только `http(s)`; клик по уведомлению откроет его в браузере.

## `POST /app/activity`: живая активность в пилюле

```json
{ "app": "Daily Note", "id": "tasks", "text": "Задачи 3/5", "progress": 0.6, "ttlSec": 900 }
```

```json
{ "app": "Daily Note", "id": "rest", "text": "Отдых", "endsAt": 1768000000000, "durationSec": 90 }
```

| Поле | Что значит |
|---|---|
| `app`, `id` | вместе задают активность: повторный вызов с теми же значениями обновляет её |
| `text` | подпись (до 80 символов) |
| `progress` | 0…1, кольцо вокруг значка; нет поля — без кольца |
| `endsAt` | unix-время окончания в миллисекундах: остров сам отсчитывает «мин:сек» и убирает активность через 4 с после конца |
| `durationSec` | полная длительность для кольца при `endsAt` |
| `ttlSec` | сколько секунд держать без обновлений (5…3600, по умолчанию 600) |
| `clear` | `true`: убрать активность сразу |

Одновременно держится не больше 8 активностей. Если их несколько, колесо мыши над пилюлей переключает между ними, как между музыкой и таймером.

## `POST /app/tasks/sync`: общий список задач на сегодня

Приложение присылает свой список задач на сегодня, остров показывает его на вкладке «Задачи» и отвечает тем, что за это время
сделали на острове. Так галочка, поставленная в любом из двух мест, появляется в обоих.

```json
{ "app": "Daily Note", "day": "2026-11-17", "tasks": [ { "id": "a1", "text": "Зарядка", "done": false } ] }
```

Ответ:

```json
{ "actions": [ { "type": "toggle", "id": "a1", "text": "", "done": true }, { "type": "add", "id": "…", "text": "Купить хлеб", "done": false } ] }
```

- `day` — дата приложения в виде `yyyy-MM-dd`; принимается только сегодняшний список.
- `toggle`: отметить или снять отметку у задачи `id`. `add`: создать задачу с текстом `text` (уже отмеченную, если `done`).
- Каждое действие приходит **один раз**. Приложение применяет его и при следующем вызове присылает уже обновлённый список;
  до этого остров продолжает показывать своё изменение. Если приложение действие не применило, верх берёт его список.
- Вызывать стоит при каждом изменении списка и раз в несколько секунд, пока приложение открыто. Пока вызовы идут
  (последний не старше двух минут), новые задачи с острова уходят в приложение; иначе остаются задачами острова.
- До 200 задач, текст до 300 знаков. Остров без этой возможности отвечает пустым телом: это значит «не поддерживается».

## Пример (PowerShell)

```powershell
$token = (Get-Content "$env:LOCALAPPDATA\DynamicIsland\bridge.token").Trim()
$body  = @{ app = "Мой скрипт"; id = "demo"; text = "Идёт работа"; progress = 0.4 } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri http://localhost:47811/app/activity `
  -Headers @{ "X-Island-Token" = $token } -ContentType "application/json" -Body $body
```
