# Мост для расширения браузера

Расширение из папки [`extension/`](../extension/) общается с островом по `http://localhost:47811` (только этот ПК).
Это **отдельный маршрут `/ext/*`** со своим ключом: общий мост для приложений ([app-bridge.md](app-bridge.md))
намеренно отклоняет всё, что идёт из браузера (заголовок `Origin`), а расширение всегда его шлёт.

## Условия доступа

Остров отвечает на `/ext/*` только если выполнено всё:

1. В «Настройки → Поведение → Расширение для браузера» включён переключатель (по умолчанию **выключен**).
2. Заголовок `Origin` имеет вид `chrome-extension://…` или `moz-extension://…`. Страница сайта такой `Origin` отправить не может.
3. Заголовок `X-Island-Ext-Token` совпадает с ключом из `%LOCALAPPDATA%\DynamicIsland\ext.token` (сравнение с постоянным временем).
   Ключ копируется кнопкой «Скопировать ключ», «Новый ключ» делает старый недействительным.
4. Метод `POST`, `Content-Type: application/json`, тело до 100 КБ, запрос с этого же ПК.

Ответы с CORS-заголовками получает только такое расширение (`Access-Control-Allow-Origin` равен его `Origin`).
Предзапрос `OPTIONS` отвечает `204`. Без допустимого `Origin` ответ `403` без тела.
Включено, но ключ не подошёл: `401`. Связь выключена в настройках: `403 {"error":"disabled"}`.

## Маршруты

| Маршрут | Тело | Что делает остров |
|---|---|---|
| `POST /ext/ping` | `{}` | отвечает `{"ok":true,"app":"Atoll"}`: проверка связи и ключа |
| `POST /ext/note` | `{"text":"…","title":"…","url":"https://…"}` | кладёт заметку в начало списка («Заметки») и показывает уведомление «Сохранено в заметки»; `url` только `http(s)` |
| `POST /ext/check` | `{"issues":3,"lang":"ru-RU"}` | показывает в пилюле на 25 секунд «LanguageTool · замечаний: 3» (как активность другого приложения) |

Длины: `text` до 20 000 знаков, `title` до 200, `url` до 500, `lang` до 20.

## Что остров не делает

Остров ничего не отправляет наружу и не читает страницы. Текст на проверку расширение само отправляет на выбранный
сервер LanguageTool, и только по нажатию пользователя; остров получает лишь **число замечаний**.
