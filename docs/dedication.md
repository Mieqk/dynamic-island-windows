# Личное посвящение (приватно)

Atoll умеет показывать личное сообщение тому, для кого сделана версия. Сами слова **не лежат в репозитории**:
они в локальном файле `dedication.json`, поэтому публичный форк остаётся приватным. Без файла в приложении ничего не меняется.

## Где лежит файл

Любой из двух вариантов (первый имеет приоритет):

1. `%APPDATA%\DynamicIsland\dedication.json` (папка появляется после первого запуска Atoll, или создайте её сами);
2. рядом с `DynamicIsland.exe`.

Файл читается при запуске: после правки перезапустите Atoll. `dedication.json` внесён в `.gitignore`, чтобы его не закоммитили по ошибке.

## Что он включает

| Поле | Что даёт |
|---|---|
| `title` | заголовок приветствия (имя, обращение) |
| `toast` | короткое приветствие, которое остров показывает **один раз** при первом запуске |
| `message`, `signature` | карточка «О версии» вверху «Настройки → Внешний вид» (с пометкой об оригинале Fuwni и лицензии MIT) |
| `themeName` | личная тема с этим названием первой в списке тем (тёплый сливовый фон, мягкий розовый акцент) |
| `versionLabel` | подпись значка в трее вместо «Atoll» |
| `specialDates` | поздравления в нужные дни: `date` в формате `MM-dd`, показывается раз в год; запись с пустой или неверной датой пропускается |

Образец: [dedication.sample.json](dedication.sample.json).
